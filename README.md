# LabVIEW-Nextron-MPS-CHL-Temperature-Control
LabVIEW drivers and a control application for serial communication with the Nextron MPS-CHL temperature controller. Enables reading and setting temperature, configuring ramps and time bases, and manual or programmed temperature control. Developed for RT–450 °C MPS unit. LabVIEW version: 23.0 SP1
